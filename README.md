## My Geo Journey

One of the main interactive features of the portfolio is the **Geo Journey** section.

The map represents important locations in my academic and professional journey:

- **Beijing, China**
- **University of Southern California — Los Angeles, CA**
- **Maryland, USA**

The interactive map allows users to:

- Pan and zoom
- Explore geographic markers
- View location popups
- Navigate directly to individual locations
- Display my complete geographic journey

The map was built using **Leaflet** with **OpenStreetMap** as the basemap.
